## 3. SEO Cutover Verification Checklist

- [x] **Title Tags**: Descriptive, unique `<title>` implemented across all 11 pages.
- [x] **Meta Descriptions**: Compelling meta descriptions with primary keywords, localized to Dhaka/Bangladesh.
- [x] **Canonical URLs**: Canonical link tags with trailing slash consistency.
- [x] **Robots**: `public/robots.txt` present (`User-agent: *`, `Allow: /`, `Sitemap: https://niengineeringbd.com/sitemap.xml`).
- [x] **Sitemap**: `public/sitemap.xml` verified containing all production canonical routes.
- [x] **Open Graph & Twitter**: OG Title, Description, Image, Type, and Twitter card tags implemented in `Layout.astro`.
- [x] **JSON-LD Structured Data**:
  - `LocalBusiness` & `EmergencyService` Schema in `Layout.astro`
  - `FAQPage` Schema in `index.astro`
- [x] **Image Alt Text**: Alt tags verified on all product cards, project case studies, and partner logos.
- [x] **Heading Hierarchy**: Exactly one `<h1>` per page with semantic `<h2>`, `<h3>` subdivisions.
- [x] **404 Handling**: Custom 404 page required in Astro (`src/pages/404.astro`).
- [x] **Trailing-Slash Policy**: Consistent trailing slash policy enforced in Astro config (`trailingSlash: 'always'`).
- [x] **Domain Canonicalization**: Enforce `http` → `https` and `www` → non-www redirect at DNS/CDN level.
